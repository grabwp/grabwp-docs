# GrabWP Tenancy Pro

Pro extends the free plugin with full isolation - giving each tenant site its own database, plugins, themes, and content. Built for agencies and SaaS builders who need stronger separation between sites.

## What's Included

### Dedicated Database Per Site
Each site can run on its own MySQL or SQLite database - completely separate from other sites. No shared tables, no shared data.

### Per-Site Plugins & Themes
Each tenant site gets its own set of plugins and themes. You control what's available - tenants can't see or install anything from your main site.

### Content Isolation
Control what content each site can access - posts, pages, and media are fully isolated per site.

### Backup & Restore
Back up any individual tenant site and restore it at any time, including its database, uploads, and settings.

### Tenant Cloning
Duplicate any existing tenant site into a new one in 7 automated steps - validate, export, import, copy uploads, symlink extensions, fix URLs, cleanup. Useful for staging/testing setups or spinning up pre-configured sites quickly.

→ [Tenant Cloning guide](/grabwp-tenancy-pro/pro-tenant-cloning)

### Domain Symlink Management
Add or remove alternate domains for any tenant site without duplicating files. The plugin creates a server-level symlink so multiple domains serve the same tenant.

### Advanced Admin Dashboard
Extended admin UI with per-site configuration panels for isolation settings, extensions, backups, cloning, and domain management.

## Requirements

- **GrabWP Tenancy** (free base plugin) must be installed and active first
- WordPress 5.0 or later
- PHP 7.4 or later
