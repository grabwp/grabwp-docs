**Short answer:** full version-by-version changelogs live on the GrabWP changelog page and in each plugin's `readme.txt` file. This page tracks when the documentation hub was verified against plugin releases.
**Needs:** Free

## Where the changelog lives

- **GrabWP website changelog:** [https://grabwp.com/changelog](https://grabwp.com/changelog)
- **WordPress.org plugin page (Base):** [https://wordpress.org/plugins/grabwp-tenancy/#developers](https://wordpress.org/plugins/grabwp-tenancy/#developers)
- **Inside wp-admin:** click **View details** on any GrabWP plugin row under **Plugins**, or read the `== Changelog ==` section in the plugin's `readme.txt` file.
- **Product roadmap:** [https://grabwp.com/roadmap](https://grabwp.com/roadmap)

## Documentation verification log

- **2026-11-03:** Verified against Base 1.1.15, Pro 1.1.18, WaaS 1.1.25, Partner 1.4.2 and the new Custom Fields 1.0.0 add-on. Pages updated for this release:
  - **Status and setup wizard:** the shared server check with **Hosting setup**, **Tenant file safety**, **System Information** and **Support diagnostics** ([Install GrabWP](/manage-sites/install#what-the-server-check-shows), [What to send when you ask for help](/help/getting-help)).
  - **Hosting:** [Hosting setup checks](/help/hosting-requirements#hosting-setup-checks), removing leftover Multisite settings with Undo ([Settings in wp-config.php that stop GrabWP](/help/hosting-requirements#settings-in-wp-configphp-that-stop-grabwp)), OpenLiteSpeed path permalinks and the object cache change ([Hosting with xCloud](/help/hosting-with-xcloud), [Path URLs show 404](/help/path-urls-return-404), [Site login fails](/help/site-login-fails)).
  - **Settings and safety:** **Hide Themes Screen** ([Free settings](/manage-sites/free-settings)), the [Tenant file safety warning](/help/client-cannot-install-plugins#tenant-file-safety-warning), and the integrity guard that repairs only GrabWP blocks ([Install GrabWP](/manage-sites/install#plugin-general)).
  - **Pro:** safer restore messages ([Backup, restore or save errors](/help/backup-restore-and-save-problems#if-a-restore-fails)) and the wizard **Site defaults** choices.
  - **WaaS:** the wizard **Storefront** template step ([Set up WaaS](/sell-sites/set-up-waas)), verification codes on sites with a persistent object cache ([Signup problems](/help/signup-problems)), and the new [Custom fields at signup](/sell-sites/custom-fields) add-on.
- **2026-10-30:** Unified documentation hub launched, verified against Base 1.1.14, Pro 1.1.17, and WaaS 1.1.24 (along with Stripe 1.1.7, SePay 1.1.5, Xendit 1.0.5, Discounts 1.0.0, and GrabWP Restore 1.0.5).
