**Short answer:** full version-by-version changelogs live on the GrabWP changelog page and in each plugin's `readme.txt` file. This page tracks when the Knowledge Base was verified against plugin releases and which KB pages changed.

## Where the changelog lives

- **GrabWP website changelog:** [https://grabwp.com/changelog](https://grabwp.com/changelog)
- **WordPress.org plugin page (Base):** [https://wordpress.org/plugins/grabwp-tenancy/#developers](https://wordpress.org/plugins/grabwp-tenancy/#developers)
- **Inside wp-admin:** click **View details** on any GrabWP plugin row under **Plugins**, or read the `== Changelog ==` section in the plugin's `readme.txt` file.

## Knowledge Base verification log

- **2026-10-29:** KB launched, verified against Base 1.1.14, Pro 1.1.17, WaaS 1.1.24 (plus Stripe 1.1.7, SePay 1.1.5, Xendit 1.0.5, Discounts 1.0.0 and GrabWP Restore 1.0.5).
