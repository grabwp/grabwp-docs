**Short answer:** use these five pages before you install GrabWP to choose which plugins you need, verify your server requirements, pick a web server and select a payment provider.

## Pages in this section

- [Base, Pro or WaaS](/kb/choose/free-pro-waas): feature comparison across the three main plugins and add-ons.
- [Hosting requirements](/kb/choose/hosting-requirements): WordPress and PHP minimums, folder permissions, PHP extensions, cron and email.
- [Apache, LiteSpeed and Nginx](/kb/choose/web-server-guide): how routing and domain symlinks work on each web server.
- [Notes for xCloud hosting](/kb/choose/hosting-with-xcloud): setup notes tested by the GrabWP team on an Ubuntu VPS with xCloud.
- [Payment providers](/kb/choose/payment-providers): built-in billing adapters, payment add-on plugins and manual trials without a gateway.
